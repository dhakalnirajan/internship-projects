1. Architecture Overview

The K3-Edu model is a dense Transformer with $L = 12$ layers, embedding dimension $d_{\text{model}} = 768$, and $h = 12$ attention heads. Unlike the full Kimi K3 which employs Mixture-of-Experts (MoE), this educational variant uses a dense parameter layout. The architecture interleaves two attention mechanisms in a 3:1 ratio: three layers of Kimi Delta Attention (KDA) followed by one layer of Multi-Head Latent Attention (MLA), repeated across the stack.

Each layer follows the pre-norm residual formulation. For layer $\ell$, the computation is:

$$\mathbf{h}'_{\ell} = \mathbf{h}_{\ell-1} + \text{Attention}_{\ell}\bigl(\text{RMSNorm}(\mathbf{h}_{\ell-1})\bigr)$$ $$\mathbf{h}_{\ell} = \mathbf{h}'_{\ell} + \text{FFN}_{\ell}\bigl(\text{RMSNorm}(\mathbf{h}'_{\ell})\bigr)$$

where $\mathbf{h}_0 = \mathbf{E} \mathbf{x}$ is the token embedding lookup. The output logits are computed as $\mathbf{z} = \mathbf{W}_{\text{out}} \cdot \text{RMSNorm}(\mathbf{h}_L) \in \mathbb{R}^{B \times T \times V}$, with vocabulary size $V$.

Key Design Decisions. The 3:1 KDA-to-MLA ratio is not arbitrary. KDA provides $\mathcal{O}(T)$ linear attention complexity, while MLA retains the expressive power of full quadratic attention for critical layers. This hybrid design reduces the average per-layer complexity from $\mathcal{O}(T^2)$ to approximately $\frac{3}{4}\mathcal{O}(T) + \frac{1}{4}\mathcal{O}(T^2)$, which for long sequences ($T = 8192$) yields substantial savings.

2. Kimi Delta Attention (KDA)

KDA replaces the standard softmax attention with a linear recurrent attention mechanism gated by channel-wise forgetting factors. It is derived from the observation that the full attention matrix $\text{softmax}(\mathbf{Q}\mathbf{K}^\top / \sqrt{d_k})$ can be approximated via kernel feature maps, but KDA goes further by introducing a state-space interpretation.

2.1 The Recurrence

At each timestep $t$ and for each head, KDA maintains a memory state $\mathbf{S}_t \in \mathbb{R}^{d_k \times d_k}$. The recurrence is:

$$\mathbf{S}_t = \bigl(\mathbf{I} - \beta_t \cdot \mathbf{k}_t \mathbf{k}_t^\top\bigr) \cdot \text{Diag}(\boldsymbol{\alpha}_t) \cdot \mathbf{S}_{t-1} + \beta_t \cdot \mathbf{k}_t \mathbf{v}_t^\top$$
State $\mathbf{S}_t$. A $d_k \times d_k$ matrix that accumulates key-value outer products, modulated by a forget gate $\boldsymbol{\alpha}_t$ and an update strength $\beta_t$. This is fundamentally a gated associative memory.

The output at timestep $t$ is then:

$$\mathbf{o}_t = \mathbf{S}_t \mathbf{q}_t$$

where $\mathbf{q}_t, \mathbf{k}_t, \mathbf{v}_t \in \mathbb{R}^{d_k}$ are the query, key, and value vectors for the current token. Note the absence of softmax — the normalization is implicit in the recurrent state dynamics.

2.2 Channel-Wise Gating

The forget gate $\boldsymbol{\alpha}_t$ and update strength $\beta_t$ are computed from the input $\mathbf{x}_t$ via learned projections:

$$\boldsymbol{\alpha}_t = \sigma\bigl(\mathbf{W}_{\text{gate}} \mathbf{x}_t\bigr) \in (0,1)^{d_k}$$ $$\beta_t = \sigma\bigl(\mathbf{W}_{\beta} \mathbf{x}_t\bigr) \in (0,1)$$

where $\sigma$ denotes the sigmoid function. The gate $\boldsymbol{\alpha}_t$ operates per-channel (each dimension of the key space has its own decay rate), while $\beta_t$ is a scalar controlling how much new information enters the state. This is analogous to the input and forget gates in LSTM networks, but applied to the outer-product memory state rather than a vector.

2.3 Chunkwise Parallel Form

For training efficiency, the recurrence is unrolled in chunks of size $C = 128$. Within a chunk, the computation is parallelized using a scan (prefix-sum) operation. Consider chunk $c$ spanning timesteps $[t_c, t_c + C)$. Define the transition matrix:

$$\mathbf{A}_t = \bigl(\mathbf{I} - \beta_t \mathbf{k}_t \mathbf{k}_t^\top\bigr) \text{Diag}(\boldsymbol{\alpha}_t)$$

Then the state at the end of the chunk is:

$$\mathbf{S}_{t_c+C-1} = \Bigl(\prod_{t=t_c}^{t_c+C-1} \mathbf{A}_t\Bigr) \mathbf{S}_{t_c-1} + \sum_{t=t_c}^{t_c+C-1} \Bigl(\prod_{\tau=t+1}^{t_c+C-1} \mathbf{A}_\tau\Bigr) \beta_t \mathbf{k}_t \mathbf{v}_t^\top$$

The product $\prod \mathbf{A}_t$ is computed in parallel via a binary-tree reduction (Blelloch scan), yielding $\mathcal{O}(\log C)$ parallel depth. The chunk size $C = 128$ balances parallelism against the numerical stability of multiplying many $d_k \times d_k$ matrices.

2.4 Complexity Analysis

Standard attention requires computing $\mathbf{Q}\mathbf{K}^\top \in \mathbb{R}^{T \times T}$, costing $\mathcal{O}(T^2 d_k)$ operations and $\mathcal{O}(T^2)$ memory for the attention matrix. KDA reduces this to:

$$\text{Time: } \mathcal{O}(T \cdot d_k^2) \quad \text{Memory: } \mathcal{O}(d_k^2)$$

Since $d_k = 64$ is constant, KDA achieves linear complexity in sequence length. For $T = 8192$, this is a reduction from $\sim$67M to $\sim$524K operations per head — a factor of 128.

2.5 Why It Works

The key insight is that $\mathbf{S}_t$ encodes a kernel regression over past keys and values. Expanding the recurrence without gates ($\alpha_t = 1, \beta_t = 1$):

$$\mathbf{S}_t = \sum_{i=1}^{t} \mathbf{k}_i \mathbf{v}_i^\top, \quad \mathbf{o}_t = \sum_{i=1}^{t} (\mathbf{q}_t^\top \mathbf{k}_i) \mathbf{v}_i$$

This is precisely the linear attention kernel $\phi(\mathbf{q})^\top \phi(\mathbf{k})$ with $\phi(\mathbf{x}) = \mathbf{x}$. The gates $\boldsymbol{\alpha}_t$ and $\beta_t$ introduce data-dependent decay, allowing the model to selectively forget irrelevant context — a capability absent from standard linear attention.

3. Multi-Head Latent Attention (MLA)

MLA appears once per block of four layers. It compresses the key-value cache via low-rank projections, reducing the memory footprint during inference while preserving full attention expressiveness during training.

3.1 Compressed KV Projections

Standard MHA projects inputs to $\mathbf{Q}, \mathbf{K}, \mathbf{V} \in \mathbb{R}^{d_{\text{model}}}$ using three separate matrices, each of size $d_{\text{model}} \times d_{\text{model}}$. MLA instead uses a compressed latent representation:

$$\mathbf{c}_{\text{kv}} = \mathbf{W}_{\text{dkv}} \mathbf{x} \in \mathbb{R}^{r_{\text{kv}}}$$

where $r_{\text{kv}} \ll d_{\text{model}}$ is the KV LoRA rank (typically $r_{\text{kv}} = 128$ or $256$). The keys and values are then up-projected from this compressed vector:

$$\mathbf{k}_i = \mathbf{W}_{\text{uk}}^{(i)} \mathbf{c}_{\text{kv}} \in \mathbb{R}^{d_k}, \quad \mathbf{v}_i = \mathbf{W}_{\text{uv}}^{(i)} \mathbf{c}_{\text{kv}} \in \mathbb{R}^{d_v}$$

for each head $i \in \{1, \dots, h\}$. During inference, only $\mathbf{c}_{\text{kv}} \in \mathbb{R}^{r_{\text{kv}}}$ needs to be cached per token, rather than the full $\mathbf{k}, \mathbf{v} \in \mathbb{R}^{h \times d_k}$.

3.2 Decoupled RoPE

Rotary Position Embedding (detailed in §5) is applied to a separate subset of dimensions. The query and key are split into:

$$\mathbf{q}_i = [\mathbf{q}_i^{\text{nope}}; \mathbf{q}_i^{\text{rope}}], \quad \mathbf{k}_i = [\mathbf{k}_i^{\text{nope}}; \mathbf{k}_i^{\text{rope}}]$$

where $\mathbf{q}_i^{\text{nope}}$ comes from the up-projection of $\mathbf{c}_{\text{kv}}$ and $\mathbf{q}_i^{\text{rope}}$ comes from a separate projection $\mathbf{W}_{\text{q-rope}} \mathbf{x}$. The RoPE-applied dimensions are not compressed, ensuring positional information is not degraded by the low-rank bottleneck.

3.3 Attention Computation

With decoupled RoPE, the attention score for head $i$ becomes:

$$\text{score}_{ij}^{(i)} = \frac{1}{\sqrt{d_k}} \Bigl( \mathbf{q}_i^{\text{nope}\top} \mathbf{k}_j^{\text{nope}} + \mathbf{q}_i^{\text{rope}\top} \mathbf{R}_{\Theta, i-j} \mathbf{k}_j^{\text{rope}} \Bigr)$$

where $\mathbf{R}_{\Theta, i-j}$ is the rotary matrix encoding relative position $i-j$. The output is:

$$\mathbf{o} = \mathbf{W}_{\text{o}} \cdot \text{Concat}\bigl[\text{softmax}(\text{score}^{(1)})\mathbf{V}^{(1)}, \dots, \text{softmax}(\text{score}^{(h)})\mathbf{V}^{(h)}\bigr]$$

3.4 Memory Savings

For a sequence of length $T$, standard MHA caches $2 \cdot h \cdot d_k \cdot T$ floats per layer. MLA caches $r_{\text{kv}} \cdot T$ floats for the compressed KV plus $d_{\text{rope}} \cdot T$ for the RoPE keys. The compression ratio is:

$$\rho = \frac{2 h d_k}{r_{\text{kv}} + d_{\text{rope}}}$$

With $h = 12$, $d_k = 64$, $r_{\text{kv}} = 256$, $d_{\text{rope}} = 64$, we obtain $\rho = 1536 / 320 = 4.8\times$ memory reduction per MLA layer.

4. Attention Residuals (AttnRes)

AttnRes replaces the fixed residual connection $\mathbf{h}_{\ell} = \mathbf{h}_{\ell-1} + \text{Layer}(\mathbf{h}_{\ell-1})$ with a depth-wise attention mechanism that learns how to aggregate information from all previous layers.

4.1 Block Structure

The 12 layers are partitioned into $B = 4$ blocks, each containing $L/B = 3$ layers. Within a block, standard residuals are used. Between blocks, AttnRes computes a weighted combination of all previous block outputs.

4.2 The Aggregation Formula

Let $\mathbf{v}_b \in \mathbb{R}^{d}$ denote the output of block $b$ (after RMSNorm). For layer $\ell$ in block $b$, the AttnRes-modified residual is:

$$\mathbf{h}_{\ell} = \sum_{i=0}^{b-1} \alpha_{i \to \ell} \cdot \mathbf{v}_i$$

where the aggregation weights $\alpha_{i \to \ell}$ are computed via a softmax over previous blocks:

$$\alpha_{i \to \ell} = \frac{\exp\bigl(\mathbf{w}_{\ell}^\top \text{RMSNorm}(\mathbf{v}_i) / \sqrt{d}\bigr)}{\sum_{j=0}^{b-1} \exp\bigl(\mathbf{w}_{\ell}^\top \text{RMSNorm}(\mathbf{v}_j) / \sqrt{d}\bigr)}$$

Here $\mathbf{w}_{\ell} \in \mathbb{R}^{d}$ is a learnable pseudo-query vector associated with layer $\ell$, initialized to zero so that the model initially behaves like a standard residual network (uniform aggregation). During training, $\mathbf{w}_{\ell}$ learns which previous blocks are most relevant for the current computation.

4.3 Why Depth-Wise Attention?

Standard Transformers suffer from representation collapse in deep layers: later layers tend to overwrite early-layer features (syntactic structure, entity mentions) with high-level semantic information. AttnRes explicitly preserves access to all depth levels via the weighted sum. The softmax ensures the weights form a valid probability distribution, and the $1/\sqrt{d}$ scaling prevents sharp attention peaks early in training.

Initialization. Setting $\mathbf{w}_{\ell} = \mathbf{0}$ at initialization yields $\alpha_{i \to \ell} = 1/b$ — a uniform average over previous blocks. This preserves trainability: the model starts as a "soft residual" and learns to specialize its depth-wise attention as training progresses.

4.4 Computational Overhead

AttnRes adds $\mathcal{O}(B \cdot d)$ operations per layer, where $B = 4$ is the number of blocks. For $d = 768$, this is 3,072 multiply-adds per layer — negligible compared to the $\mathcal{O}(T \cdot d^2)$ cost of the attention mechanism itself.

5. Feed-Forward Network (SwiGLU)

The FFN employs the SwiGLU activation, a gated variant that has become standard in modern LLMs. Unlike the original Transformer FFN ($\text{ReLU}(\mathbf{x}\mathbf{W}_1 + \mathbf{b}_1)\mathbf{W}_2 + \mathbf{b}_2$), SwiGLU uses three matrices and a SiLU (Swish) gate.

5.1 The SwiGLU Formula

$$\text{SwiGLU}(\mathbf{x}) = \bigl(\text{SiLU}(\mathbf{x} \mathbf{W}_{\text{gate}}) \odot (\mathbf{x} \mathbf{W}_{\text{up}})\bigr) \mathbf{W}_{\text{down}}$$

where $\odot$ denotes element-wise (Hadamard) product, and the SiLU (Sigmoid Linear Unit) is:

$$\text{SiLU}(x) = x \cdot \sigma(x) = \frac{x}{1 + e^{-x}}$$
SwiGLU as a Gated MLP. The gate projection $\mathbf{W}_{\text{gate}}$ controls which dimensions of the up-projected signal $\mathbf{x}\mathbf{W}_{\text{up}}$ are allowed to pass through. This is analogous to the gating in LSTMs but applied position-wise across the hidden dimension.

5.2 Dimensionality

The intermediate dimension is $d_{\text{ffn}} = 4 \cdot d_{\text{model}} = 3072$. Each of the three matrices has shape:

$$\mathbf{W}_{\text{gate}}, \mathbf{W}_{\text{up}} \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ffn}}}, \quad \mathbf{W}_{\text{down}} \in \mathbb{R}^{d_{\text{ffn}} \times d_{\text{model}}}$$

The total FFN parameter count per layer is $3 \cdot d_{\text{model}} \cdot d_{\text{ffn}} = 3 \cdot 768 \cdot 3072 = 7,077,888$ parameters. With 12 layers, the FFN blocks contribute $\sim$85M parameters — roughly 42% of the total model.

5.3 Why SwiGLU Over ReLU/GELU?

SwiGLU provides two advantages. First, the gating mechanism acts as a learnable sparsity controller: for any given input, roughly half the FFN dimensions are suppressed (SiLU($x$) ≈ 0 for $x \ll 0$), creating an adaptive subnetwork. Second, the smoothness of SiLU (unlike the hard zero of ReLU) yields better gradient flow. Empirically, SwiGLU-trained models achieve lower perplexity at iso-parameter budgets compared to GELU or ReLU baselines.

6. Rotary Position Embedding (RoPE)

RoPE encodes position not by adding a vector to the embedding, but by rotating the query and key vectors in their 2D subspaces by an angle proportional to their absolute position. This naturally encodes relative position in the dot product.

6.1 The Rotation Matrix

For a head dimension $d_k = 64$, RoPE treats each pair of dimensions $(2i, 2i+1)$ as a 2D plane and applies a rotation by angle $\theta_i \cdot m$ at position $m$:

$$\mathbf{R}_{\Theta, m} = \begin{pmatrix} \cos(m\theta_0) & -\sin(m\theta_0) & 0 & 0 & \cdots \\ \sin(m\theta_0) & \cos(m\theta_0) & 0 & 0 & \cdots \\ 0 & 0 & \cos(m\theta_1) & -\sin(m\theta_1) & \cdots \\ 0 & 0 & \sin(m\theta_1) & \cos(m\theta_1) & \cdots \\ \vdots & \vdots & \vdots & \vdots & \ddots \end{pmatrix}$$

where the base frequencies are:

$$\theta_i = \theta_{\text{base}}^{-2i/d_k}, \quad i \in \{0, 1, \dots, d_k/2 - 1\}$$

with $\theta_{\text{base}} = 10000$ (the standard choice). For $d_k = 64$, the frequencies range from $\theta_0 = 1$ to $\theta_{31} \approx 1/10000$.

6.2 Relative Position Property

The defining property of RoPE is that the dot product of a rotated query at position $m$ and a rotated key at position $n$ depends only on their difference $m - n$:

$$\bigl(\mathbf{R}_{\Theta, m} \mathbf{q}\bigr)^\top \bigl(\mathbf{R}_{\Theta, n} \mathbf{k}\bigr) = \mathbf{q}^\top \mathbf{R}_{\Theta, n-m} \mathbf{k}$$

This is proven by noting that $\mathbf{R}_{\Theta, m}^\top \mathbf{R}_{\Theta, n} = \mathbf{R}_{\Theta, n-m}$ (rotation matrices form a group under composition). Thus, the attention score $\mathbf{q}_m^\top \mathbf{k}_n$ encodes relative distance without explicit relative position bias terms.

6.3 Long-Context Extrapolation

For sequences longer than those seen during training, RoPE can be extrapolated by scaling $\theta_{\text{base}}$. The NTK-aware scaling replaces $\theta_{\text{base}}$ with $\theta'_{\text{base}} = \theta_{\text{base}} \cdot s^{d_k/(d_k-2)}$ where $s$ is the desired length scale factor. This redistributes rotation frequencies to better handle long-range dependencies without fine-tuning.

7. RMS Normalization

RMSNorm replaces LayerNorm with a simpler normalization that preserves the scale of the input without centering. For a vector $\mathbf{x} \in \mathbb{R}^{d}$:

$$\text{RMSNorm}(\mathbf{x}) = \frac{\mathbf{x}}{\sqrt{\frac{1}{d} \sum_{i=1}^{d} x_i^2 + \epsilon}} \odot \boldsymbol{\gamma}$$

where $\boldsymbol{\gamma} \in \mathbb{R}^{d}$ is a learnable gain parameter and $\epsilon = 10^{-6}$ prevents division by zero. Note the absence of a bias term ($\boldsymbol{\beta}$) and the absence of mean subtraction.

7.1 Comparison with LayerNorm

LayerNorm computes:

$$\text{LayerNorm}(\mathbf{x}) = \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \boldsymbol{\gamma} + \boldsymbol{\beta}$$

where $\mu = \frac{1}{d}\sum x_i$ and $\sigma^2 = \frac{1}{d}\sum (x_i - \mu)^2$. RMSNorm is strictly cheaper (one fewer reduction) and empirically performs equivalently or better in Transformers because the mean-centering is redundant: the residual connection $\mathbf{x} + \text{Layer}(\mathbf{x})$ already allows the mean to shift freely.

7.2 Backward Pass

The gradient through RMSNorm is:

$$\frac{\partial \text{RMSNorm}}{\partial x_i} = \frac{\gamma_i}{\text{RMS}(\mathbf{x})} \Bigl(1 - \frac{x_i^2}{d \cdot \text{RMS}(\mathbf{x})^2}\Bigr)$$

where $\text{RMS}(\mathbf{x}) = \sqrt{\frac{1}{d}\sum x_j^2 + \epsilon}$. The term $\bigl(1 - x_i^2 / (d \cdot \text{RMS}^2)\bigr)$ acts as an adaptive scaling: dimensions with large magnitude are dampened, while small-magnitude dimensions are amplified — a form of implicit regularization.

8. Quantization: FP8 and INT8

The model supports mixed-precision training and inference using FP8 (E4M3) for activations and INT8 for weights. This section derives the quantization schemes and their error bounds.

8.1 FP8 E4M3 Format

E4M3 allocates 1 sign bit, 4 exponent bits, and 3 mantissa bits. The representable range is:

$$\text{Max} = 2^{7} \cdot (1 + 6/8) \cdot 2^{0} = 448, \quad \text{Min Normal} = 2^{-6} = 1/64 \approx 0.0156$$

(The exact minimum normal is $2^{-6} = 0.015625$, with subnormals extending to $\approx 0.00195$.) The quantization function $Q_{\text{fp8}}: \mathbb{R} \to \text{FP8}$ is:

$$Q_{\text{fp8}}(x) = \text{sign}(x) \cdot \min\bigl(448, \max(0.00195, |x|)\bigr) \cdot \frac{127}{448} \cdot \text{round}\Bigl(\frac{448}{127} \cdot \frac{|x|}{s}\Bigr)$$

where $s$ is a per-tensor scaling factor. The dequantization is $\hat{x} = Q_{\text{fp8}}(x) \cdot s \cdot (448/127)$.

8.2 INT8 Weight Quantization

Weights are quantized per-channel (or per-block) using symmetric INT8:

$$Q_{\text{int8}}(\mathbf{w}) = \text{round}\Bigl(\frac{127}{\max |\mathbf{w}|} \cdot \mathbf{w}\Bigr) \in \{-127, \dots, 127\}$$

The scale factor is $s_w = \max |\mathbf{w}| / 127$. Dequantization: $\hat{\mathbf{w}} = Q_{\text{int8}}(\mathbf{w}) \cdot s_w$.

8.3 Quantization-Aware Training (QAT)

During training, the straight-through estimator (STE) is used to propagate gradients through the non-differentiable quantization function:

$$\frac{\partial \mathcal{L}}{\partial w} = \frac{\partial \mathcal{L}}{\partial \hat{w}} \cdot \mathbf{1}_{|w| \leq 127 \cdot s_w}$$

The indicator function $\mathbf{1}_{|w| \leq 127 \cdot s_w}$ clips gradients for weights outside the representable range, preventing gradient explosion. The scale $s_w$ is updated via exponential moving average during training.

8.4 Error Analysis

The quantization error for a uniform quantizer with step size $\Delta$ is bounded by:

$$\mathbb{E}[(x - \hat{x})^2] \leq \frac{\Delta^2}{12}$$

For INT8 weights with $\max |w| = 2.5$, $\Delta = 5/256 \approx 0.0195$, giving an MSE bound of $\approx 3.2 \times 10^{-5}$. For FP8 activations, the non-uniform spacing means the error is input-dependent, but empirically remains below 1% relative error for typical activation distributions.

9. Training Pipeline

Training proceeds in two phases: base pretraining on diverse text and code, followed by instruction fine-tuning with special chat tokens.

9.1 AdamW Optimizer

The optimizer maintains first and second moment estimates for each parameter:

$$\mathbf{m}_t = \beta_1 \mathbf{m}_{t-1} + (1 - \beta_1) \mathbf{g}_t$$ $$\mathbf{v}_t = \beta_2 \mathbf{v}_{t-1} + (1 - \beta_2) \mathbf{g}_t^2$$

where $\mathbf{g}_t = \nabla_{\theta} \mathcal{L}_t$ is the gradient at step $t$. The bias-corrected estimates are:

$$\hat{\mathbf{m}}_t = \frac{\mathbf{m}_t}{1 - \beta_1^t}, \quad \hat{\mathbf{v}}_t = \frac{\mathbf{v}_t}{1 - \beta_2^t}$$

The parameter update with decoupled weight decay is:

$$\boldsymbol{\theta}_{t+1} = \boldsymbol{\theta}_t - \eta_t \Bigl(\frac{\hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon} + \lambda \boldsymbol{\theta}_t\Bigr)$$

Hyperparameters: $\beta_1 = 0.9$, $\beta_2 = 0.95$, $\epsilon = 10^{-8}$, $\lambda = 0.1$ (base) or $0.01$ (instruction).

9.2 Cosine Learning Rate with Warm Restarts

The learning rate schedule is non-monotonic. After a linear warmup of $W$ steps, the LR follows a cosine decay that resets periodically:

$$\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})\Bigl(1 + \cos\bigl(\pi \cdot \frac{t \bmod T_{\text{period}}}{T_{\text{period}}}\bigr)\Bigr)$$

After each restart, the period is multiplied by a factor (e.g., 2), creating a warm restart schedule. This helps escape local minima: the high-LR phase after each restart perturbs parameters enough to explore new basins, while the cosine decay allows fine convergence.

For base training: $\eta_{\max} = 3 \times 10^{-4}$, $W = 2000$, total steps $= 150{,}000$. For instruction tuning: $\eta_{\max} = 10^{-5}$, $W = 500$, total steps $= 30{,}000$.

9.3 Gradient Clipping

Before the optimizer step, gradients are clipped to maximum norm $\gamma = 1.0$:

$$\hat{\mathbf{g}} = \min\Bigl(1, \frac{\gamma}{\|\mathbf{g}\|_2}\Bigr) \mathbf{g}$$

This prevents gradient explosion during the early phase of training when loss landscapes are steep. The $L_2$ norm is computed over all parameters jointly (global clipping), not per-layer.

where $p_{\theta}(x_t | x_{

9.5 Gradient Accumulation

To achieve an effective batch size of $N_{\text{target}} = 32{,}768$ tokens with limited GPU memory, gradients are accumulated over $N_{\text{acc}} = \lceil N_{\text{target}} / (B \cdot T) \rceil$ forward-backward passes before calling the optimizer. The loss is averaged over the accumulation steps:

$$\bar{\mathcal{L}} = \frac{1}{N_{\text{acc}}} \sum_{i=1}^{N_{\text{acc}}} \mathcal{L}_i, \quad \bar{\mathbf{g}} = \frac{1}{N_{\text{acc}}} \sum_{i=1}^{N_{\text{acc}}} \mathbf{g}_i$$

10. Inference Pipeline

During inference, the model generates tokens autoregressively. Several optimizations reduce latency and memory.

10.1 KV Cache

For autoregressive generation, the key and value tensors for all previous tokens can be cached, avoiding recomputation. At step $t$, only the new token's key $\mathbf{k}_t$ and value $\mathbf{v}_t$ are computed and appended:

$$\mathbf{K}_{\text{cache}}^{(t)} = [\mathbf{K}_{\text{cache}}^{(t-1)}; \mathbf{k}_t^\top] \in \mathbb{R}^{t \times d_k}, \quad \mathbf{V}_{\text{cache}}^{(t)} = [\mathbf{V}_{\text{cache}}^{(t-1)}; \mathbf{v}_t^\top] \in \mathbb{R}^{t \times d_v}$$

The attention computation at step $t$ becomes:

$$\mathbf{o}_t = \text{softmax}\Bigl(\frac{\mathbf{q}_t \mathbf{K}_{\text{cache}}^{(t)\top}}{\sqrt{d_k}}\Bigr) \mathbf{V}_{\text{cache}}^{(t)}$$

Memory per layer for the KV cache: $2 \cdot h \cdot d_k \cdot T_{\max}$ floats. For $h=12$, $d_k=64$, $T_{\max}=8192$, this is $2 \cdot 12 \cdot 64 \cdot 8192 = 12{,}582{,}912$ floats $\approx$ 48 MB per layer in FP32, or 6 MB in INT8.

10.2 Temperature Sampling

Given logits $\mathbf{z} \in \mathbb{R}^{V}$, temperature $\tau$ rescales the distribution before sampling:

$$p_i = \frac{\exp(z_i / \tau)}{\sum_{j=1}^{V} \exp(z_j / \tau)}$$

As $\tau \to 0$, the distribution concentrates on $\arg\max_i z_i$ (greedy decoding). As $\tau \to \infty$, the distribution approaches uniform. The default $\tau = 0.7$ provides a balance between coherence and diversity.

10.3 Top-$k$ and Top-$p$ Filtering

Top-$k$: Retain only the $k$ largest logits, setting others to $-\infty$ before softmax. Default $k = 40$.

Top-$p$ (nucleus): Sort logits descending as $z_{(1)} \geq z_{(2)} \geq \dots \geq z_{(V)}$. Find the smallest $k'$ such that:

$$\sum_{i=1}^{k'} \frac{\exp(z_{(i)} / \tau)}{\sum_{j=1}^{V} \exp(z_{(j)} / \tau)} \geq p$$

Retain only $\{z_{(1)}, \dots, z_{(k')}\}$. Default $p = 0.9$. This adapts the cutoff to the confidence of the model: for confident predictions, only a few tokens are considered; for uncertain predictions, many are.

10.4 Repetition Penalty

To reduce degenerate repetition, logits for tokens already generated are penalized:

$$z'_i = \begin{cases} z_i / \rho & \text{if } i \in \text{prev_tokens} \\ z_i & \text{otherwise} \end{cases}$$

where $\rho = 1.0$ means no penalty, $\rho > 1.0$ suppresses repeats, and $\rho < 1.0$ encourages them. A typical value is $\rho = 1.1$.

10.5 Perplexity Evaluation

Perplexity measures how well the model predicts a held-out corpus:

$$\text{PPL} = \exp\Bigl(-\frac{1}{N} \sum_{t=1}^{N} \log p_{\theta}(x_t | x_{

Lower perplexity indicates better prediction. For a well-trained 200M model on diverse text, expected PPL is in the range 15–25 on standard benchmarks.

11. Parameter Accounting

In an MoE architecture, this ratio would be $1/E$ where $E$ is the number of experts, allowing larger total capacity with the same inference cost. K3-Edu omits MoE for pedagogical clarity.

11.1 FLOPs Per Forward Pass

For a single token (batch size 1, sequence length $T$):

$$\text{FLOPs} \approx 2 \cdot N_{\text{params}} + 2 \cdot L \cdot h \cdot T \cdot d_k$$

The first term is matrix multiplication (2 FLOPs per multiply-add), the second is attention. For $T = 1024$:

$$\text{FLOPs} \approx 400 \text{M} + 2 \cdot 12 \cdot 12 \cdot 1024 \cdot 64 = 400 \text{M} + 18.9 \text{M} \approx 419 \text{M}$$

At 100 tokens/sec on a modern CPU, this requires $\approx 42$ GFLOP/s sustained throughput — well within reach of AVX-512 optimized kernels.
