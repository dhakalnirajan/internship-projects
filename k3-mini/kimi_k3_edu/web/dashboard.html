what this is

Live view of a K3-Edu training run — loss/perplexity curves, throughput, learning-rate schedule, cost, hardware telemetry and per-source data streaming, updated every 2 s.

how it works

The C trainer appends one JSON line per step to runs/<run>/metrics.jsonl (via include/metrics.h). A stdlib-only Python server (scripts/monitor_server.py) tails the file with byte-offset polling; this page renders it. Hardware values are really detected at monitor start (scripts/detect_hardware.py), not assumed.

interactions

Hover any chart for per-step values. The global controls switch x-axis between step-wise and time-wise, y-axis between linear and log, and an EMA smoothing slider (raw points always shown faintly under the smoothed line).

benchmarks & sources

Benchmark cards appear when the trainer emits metrics_emit_benchmark(); the sampler page appears when it emits metrics_emit_source(). Both are optional — a minimal run shows curves only.
